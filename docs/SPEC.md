# 画像のモザイク・吹き出し編集アプリ 仕様書

この文書は、このリポジトリのアプリ（以下「本アプリ」）と同じものを、別のAIや開発者が作るための仕様書です。
実際に動いているコードは同じリポジトリにあります（`index.html` `style.css` `app.js` `effects.js` `annotate.js` `sw.js`）。迷ったときはコードの動きを正とします。

- 第1部：アプリとして作る場合の仕様（iPhoneのブラウザで動くWebアプリ）
- 第2部：AIエージェント（Meta Muse など）が、チャットの中で同じ編集を行う場合の仕様
- 付録：そのまま貼れる依頼文

---

# 第1部 アプリの仕様

## 1. 目的と前提

**目的**：画像の一部を隠す（モザイク・ぼかし・塗りつぶし）ことと、文字や吹き出しを書き込むことを、iPhoneで手早く行う。

**守ること（最重要）**
1. 画像は端末の外へ一切送らない。処理はすべてブラウザの中で行う。
2. 元の画像は上書きしない。保存は常に別ファイルとして行う。
3. 保存形式は元と同じにする。PNGは劣化なし（可逆）、JPEG・HEICは品質95%。
4. ファイル名は元の名前（拡張子の大文字・小文字も含む）を初期値にし、保存時に任意で変更できる。
5. 保存した画像からはメタデータ（撮影日時・位置情報・カメラ情報・PNGのテキスト情報など）を削除する。色の情報（Display P3 などの色空間）は残してよい。
6. PNGでは、編集していないピクセルが元画像と1ピクセルも違わないこと。

**動作環境**
- iPhoneのSafari（ホーム画面に追加して使うPWA）が主な対象。パソコンのブラウザでも動くこと。
- HTTPSで公開する（GitHub Pages など）。ビルド作業は不要。外部ライブラリは使わない。
- 一度開いたあとはオフラインでも動く（Service Worker でアプリ本体をキャッシュする）。

## 2. 画面構成

```
┌──────────────────────────────┐
│ [開く] ファイル名            ↶ ↷ [保存] │ 上部
│        [1/3枚▾] 848×1280 px・PNG    │ ← ファイル名を押すと画像の一覧が開く
├──────────────────────────────┤
│                              │
│   画像（淡いグレーの作業台の上・影付き）   │ 中央
│                 [全体 18% 等倍]    │
├──────────────────────────────┤
│ 道具（アイコン＋名前のボタン）            │
│ 種類・強さ・色などの設定                 │ 下部（パネル）
│ ヒント                [解除] [適用] │
├──────────────────────────────┤
│   [ 隠す ]         [ 書き込む ]    │ 最下部のタブ
└──────────────────────────────┘
```

**配色（明るい基調・モードで色分け）**

| 用途 | 色 |
|---|---|
| 面（ボタン・ダイアログ） | `#ffffff` |
| 淡い面 | `#eef0f6` |
| 作業台（画像の背景） | `#e2e5ee` |
| 文字 | `#1e2233` |
| 補助の文字 | `#687087` |
| 線 | `#d9dde8` |
| 隠すモードの色（藍色） | `#3d48b8`、淡い色 `#e3e6fb`、パネルの背景 `#eef0fb` |
| 書き込むモードの色（青緑） | `#0e8a85`、淡い色 `#d6f0ee`、パネルの背景 `#e8f6f5` |
| 削除・エラー | `#c0392b` |

- 保存ボタン・選択中の道具・パネルの背景・画像上の選択枠の色は、今のモードの色にする。どちらのモードかを色で取り違えないようにするのが目的。
- 画面が狭いとき（幅380px以下）は「開く」をアイコンだけにする。
- パネルの高さは画面の46%まで（部品の選択中は40%まで）とし、収まらない分はパネル内でスクロールする。
- 文字入力欄は16px以上にする（iPhoneで入力時に画面が拡大されないため）。

**PC向けのレイアウト**（横幅1024px以上）
- 2列にする：左に画像（縦いっぱい）、右に幅380pxの列。右の列の一番上にモードの切り替え、その下に道具と設定（縦に並べ、はみ出す分は列の中でスクロール）。上部のバーは2列にまたがる。
- 部品の選択中も追加ボタンの名前とヒントを出す（PCは画面に余裕があるため）。

## 3. 読み込み

- 「開く」で写真ライブラリ・ファイルアプリから選ぶ（`<input type="file" multiple accept="image/*">`）。パソコンではドラッグ＆ドロップでも開ける。
- 対応形式：PNG・JPEG・HEIC・WebP（ブラウザが読める形式）。
- **最初に開くフォルダ**：`showOpenFilePicker` が使えるブラウザ（PCのChrome・Edge）では、それで開く。フォルダを指定できるボタンを出し（`showDirectoryPicker`）、指定したフォルダを IndexedDB に保存して `startIn` に渡す。指定がなければ `id` を渡して、前回開いた場所から開く。指定したフォルダが見つからないときは前回の場所から開き、その旨を表示する。使えないブラウザ（iPhoneのSafariなど）では、これまでどおり `<input type="file">` で開き、フォルダのボタンは出さない。
- 複数枚を読み込める。上限は **50枚・合計150MB**。超えた分は読み込まず、何枚読み込まなかったかを表示する。
- 読み込み量（枚数と合計サイズ）をメーターで常に確認できるようにする。8割を超えたら色を変える。
- 一覧の並び順は初期値を**ファイル名順**にする。数字は数として比べ（`IMG_2` → `IMG_10`）、大文字・小文字と全角・半角は区別しない（`Intl.Collator('ja', { numeric: true, sensitivity: 'base' })`）。並び順は「名前順」「名前の逆順」「選んだ順」から選べ、設定は端末に保存する。後から追加した画像も並び順の中に入れる。サムネイルの下にはファイル名の末尾を表示する。
- メモリ節約のため、**展開するのは表示中の1枚だけ**。他の画像は「元ファイル」と「編集手順」だけを持ち、切り替えたときに元ファイルから作り直す。
- 1677万ピクセル（4096×4096相当）を超える画像は、iPhoneでは処理できないことがある旨を警告する。
- 画像が Display P3 か判定し（PNGの iCCP・cICP、JPEG・HEICの ICCプロファイル名）、対応ブラウザなら P3 のキャンバスで処理する。これをしないと、iPhoneのスクリーンショットの色が変わる。

## 4. 表示と操作

- 2本指のピンチで拡大・縮小（最大40倍）、2本指で移動。パソコンではホイールで拡大・縮小。
- 「全体」で画面に合わせる、「等倍」で画像の1ピクセル＝画面の1ピクセル。
- 2倍以上に拡大したときは、ピクセルをくっきり表示する（補間しない）。
- 透明部分は市松模様で表示する。
- iPhoneのページ全体の拡大は止める（`gesturestart` などを無効化、`touch-action: none`）。
- 1本指で操作中に2本目の指が触れたら、描きかけ・動かしかけの操作を取り消してピンチ操作に切り替える。

## 5. 隠す（モザイク・ぼかし・塗りつぶし）

### 5.1 範囲の指定
| 道具 | 動き |
|---|---|
| 移動 | 1本指で画面を動かす |
| なぞる | 1本指でなぞった線の内側を範囲にする。なぞっている間は**なぞった軌跡だけ**を表示し（始点へは結ばない）、指を離したら閉じる |
| 四角・楕円 | ドラッグで作る。四隅でサイズ変更、内側のドラッグで移動 |

**なぞった範囲の調整**（指を離したあと）
- 線の近く（画面上22px以内）をドラッグ：その付近だけを伸ばす・縮める。半径60px（画面上）以内の点が、距離に応じて滑らかに一緒に動く（重み＝0.5＋0.5×cos(π×距離÷半径)）。伸ばした区間には点を補う。
- 外接する四角の四隅：形を保ったまま全体を拡大・縮小。
- 内側：移動。
- 新しく囲み直すときは、範囲の外側からなぞり始める（または「解除」）。

### 5.2 効果
| 効果 | 強さ（数値入力とスライダー） | 内容 |
|---|---|---|
| モザイク | ブロックの大きさ 2〜200px（初期値16） | ブロックごとの平均色で塗る。グリッドは**画像の左上を基準**にそろえる（範囲を変えてもブロックの位置がずれない）。平均はアルファで重み付け |
| ぼかし | 強さ 1〜100px（初期値12） | ガウスぼかしを3回のボックスぼかしで近似。範囲の周りもぼかしの計算に含め、端は端の色を延長。半透明の画像は乗算済みアルファで計算 |
| 塗りつぶし | 色（黒・白・グレー・任意） | 指定色で塗る |

- 適用前にプレビューを表示する。
- **合成の方法**：範囲を塗ったマスク（縁はアンチエイリアス）の濃さ t（0〜1）で、`結果 = 元 + (効果 − 元) × t` をRGBAそれぞれで計算し、外接する四角の部分だけを差し替える。t=0 のピクセルは元の値のまま。

## 6. 書き込む（文字・吹き出し・矢印・枠・スタンプ）

書き込みは保存するまで「画像とは別の部品」として持ち、何度でも選択して直せる。保存するときに画像へ描き込む。

### 6.1 共通の操作
- 部品をタップで選択、ドラッグで移動。何もない所のドラッグは画面の移動。
- 四隅でサイズ変更（中心基準）。文字とスタンプは文字サイズを比率で変える。
- 上に出る丸で回転。0°・90°・180°・270°の近く（約4°以内）では吸い付く。
- 縮小表示で部品が小さいときは、ハンドルより部品の中心の方が近ければ「移動」を優先する（ハンドルとの取り違え防止）。
- 複製・前面へ・削除・選択解除。
- 選択中は画像の一覧を隠し、追加ボタンをアイコンだけにして、画像の表示部分を確保する。

### 6.2 文字
- 内容（入力欄で打つと即反映。iPhoneの変換入力を安定させるため、画像の上で直接は打たない）
- フォント：ゴシック（ヒラギノ角ゴ）・明朝（ヒラギノ明朝）・丸ゴシック（ヒラギノ丸ゴ）。端末に入っているものを使う。
- サイズ、色、太字、縁取り（なし・色）、揃え（左・中央・右／縦書きでは上・中央・下）
- **縦書き**：列は右から左。次の文字は90°回転させる：`ー－-—―‐〜～…‥：:;；=＝()（）[]［］{}｛｝「」『』【】〈〉《》<>＜＞`。句読点 `、。，．` は右上に寄せる。小さい仮名（ぁぃぅぇぉっゃゅょゎァィゥェォッャュョヮヵヶ）は少し右上に寄せる。
- 行間は文字サイズの1.35倍。縁取りの太さは文字サイズの0.22倍。
- 簡易禁則：次の文字は行頭（列の先頭）に来ないようにする：`、。，．,.!?！？)）]］」』】〉》ー` と小さい仮名、`…‥`。

### 6.3 吹き出し
- 形：**角丸・楕円・四角・叫び・思考**。中の文字は幅（縦書きは高さ）に合わせて自動で折り返し、収まらないときは吹き出しを広げる（縮めはしない）。
- しっぽ：ドラッグで先端の位置を動かせる。思考は小さな丸3つ。
- 塗り色・線の色・線の太さ。線→塗りの順に描き、本体としっぽの境目の線を隠す（線は2倍の太さで描く）。
- 設定は「文字」「吹き出しの形・色」のタブに分ける。

**叫び・思考の形**（「吹き出しの形・色」タブ）

| 形 | 種類 | 調整できる値（スライダー） |
|---|---|---|
| 叫び | ギザギザ・爆発・電撃 | トゲの数（6〜48）、トゲの長さ（5〜60%）、不揃いさ（0〜100%） |
| 思考 | もくもく・丸いふくらみ | ふくらみの数（5〜24）、ふくらみ（5〜30%、もくもくのみ）、不揃いさ（0〜100%） |

- 「形を変える」：同じ設定のまま、乱数の種（seed）だけを変えて描き直す。形は seed から決まる（同じ値なら毎回同じ形）。
- 種類ごとの初期値：ギザギザ（16, 20%, 0%）、爆発（22, 30%, 80%）、電撃（11, 24%, 70%）、もくもく（12, 13%, 0%）、丸いふくらみ（10, –, 30%）。
- 見本12種類を用意する：①ギザギザ均一 ②ギザギザ不均一・弱め ③ギザギザ不均一・強め ④爆発 ⑤爆発・細かい ⑥電撃 ⑦もくもく均一 ⑧もくもく不均一 ⑨大きなもくもく ⑩丸いふくらみ ⑪丸いふくらみ・細かい ⑫丸いふくらみ・不均一。具体的な値と描き方は `annotate.js` の `BUILTIN_PRESETS` と `SHAPE_PATHS` を参照。

### 6.4 吹き出しの登録・呼び出し
- 選択中の吹き出しに名前を付けて登録する（初期値は「叫び・爆発1」のように自動）。同じ名前は上書きの確認をする。
- 記録する内容：形・種類・数・長さ・不揃いさ・seed・塗り・線・文字の書式（フォント・色・縁取り・太字・縦書き・揃え）・大きさ。**文字の内容と位置は記録しない**。
- 大きさ・線の太さ・文字サイズ・しっぽの位置は**画像の短辺に対する割合**で記録する（サイズの違う画像でも同じ見た目になる）。
- 呼び出すと、選択中の吹き出しに当てはめる（文字の内容・位置・回転はそのまま）。見本は形だけを当てはめる。
- 一覧には小さな見本画像を表示する。
- 保存先は端末のブラウザ（localStorage、キー `mosaic-bubble-presets`）。「書き出し」でJSONファイルに保存し、「読み込み」で戻せる。読み込むときは知っている項目と正しい値だけを受け付ける。

### 6.5 矢印・枠・スタンプ
- 矢印：両端の丸で向きと長さを変える。色・太さ・両矢印。
- 枠：四角・角丸・楕円の線。色・太さ（強調用の赤丸など）。
- スタンプ：絵文字20種（❗ ❓ ‼️ ⭐ ❤️ 👍 👉 👆 ✅ ❌ ⚠️ 💡 😊 😂 😢 😡 🎉 🔥 💦 ✨）。

新しく追加する部品の初期の大きさは、画像の短辺を基準にする（文字7%、吹き出し幅50%・高さ30%など）。

## 6.6 トリミング
- 3つ目のモード（色は琥珀色 `#a16207`、淡い色 `#fbe8c6`、パネルの背景 `#fdf3e1`）。
- 範囲は画像ごとに「元の画像の座標」で記録し、元の画像は切り落とさない。隠す編集・書き込みの座標はそのまま使える。保存時に、書き込みを重ねてから範囲で切り抜く（`getImageData` で範囲のピクセルをそのまま写す）。
- 操作：角・辺（比率が自由なとき）のドラッグで大きさを変更、内側で移動、外側のドラッグで新しく囲む。最小8px。画像の外には出さない。画像全体と同じ範囲は「トリミングなし」とする。
- 比率：自由・元の比率・1:1・4:3・3:4・16:9・9:16・4:5。比率を選ぶと、今の範囲の中心を保って、その比率で収まる一番大きな範囲にする。
- 大きさの表示：操作中は枠の上（入らなければ内側）に「幅 × 高さ px」を表示し、パネルにも大きく表示する。幅・高さの数値入力（中心を保つ。比率固定ならもう一方も合わせる）。
- トリミング画面では画像全体を表示し、範囲の外を暗くする（三分割の線も表示）。左右の「前へ・次へ」と枠の辺が近づきすぎないよう、左右に68pxずつ余白をとって表示する。隠す・書き込む画面では切り抜いた範囲だけを表示する。
- 内容が変わらない操作は「元に戻す」の履歴に残さない。トリミングの範囲も履歴に含める。
- 「他にも適用」でトリミングの範囲もコピーできる（サイズの違う画像には比率で合わせる）。

## 7. 元に戻す・やり直す
- 「隠す」と「書き込む」の両方に共通の履歴（画像ごとに最大200回）。
- 履歴は「隠す編集の一覧」と「書き込み部品の一覧」の状態として持つ。隠す編集が変わったときだけ、元画像から作り直す。
- スライダーや文字入力など、同じ項目を続けて変えたとき（1.5秒以内）は1回分にまとめる。

## 8. 複数枚の処理
- 一覧（上部のファイル名から開く）：サムネイル、前へ・次へ、一覧から外す（×）、「保存済みを外す」（保存し終わった画像だけ）、「すべて外す」。未保存の編集がある画像を外すときは確認する。印は、オレンジ＝未保存の編集あり、緑＝保存済み。
- 画像が2枚以上のときは、作業台の左右の端（縦の中央）に半透明の「‹」「›」を出す（先頭では「‹」、最後では「›」を出さない）。押せる範囲は44×88px。指を置いてほとんど動かさずに離したときだけ切り替え、ボタンから始めたドラッグでは切り替えない。キャンバスを操作中（なぞる・ピンチ・部品の移動）はボタンを反応させず薄く表示する。切り替えたら「3/15　ファイル名」を短く表示する。パソコンでは左右の矢印キーでも切り替える。
- 画像を切り替えても、各画像の編集内容と履歴は残る。適用前の選択範囲は次の画像に引き継ぐ。
- **他にも適用**：表示中の画像の編集（隠す編集・書き込みを選べる）を、選んだ画像の同じ位置に追加する。同じサイズの画像は最初から選ばれている。サイズが違う画像は縦横の比率で位置を合わせる。

## 9. 保存

| 元の形式 | 保存形式 |
|---|---|
| PNG | PNG（劣化なし） |
| JPEG | JPEG（品質95%） |
| HEIC | HEIC（品質95%）。ブラウザが書き出せなければ JPEG（品質95%）にし、そのことと拡張子が変わることを表示する |
| WebP | WebP（品質95%）。書き出せなければ PNG |

- キャンバスから書き出すことで、メタデータは自然に消える。
- 書き出した形式が本当にその形式か（`blob.type`）を確認する。
- **1枚ずつ保存**：上部の「保存」。ファイル名を変更でき、「元の名前に戻す」もある。共有メニュー（`navigator.share({ files })`）で「画像を保存」（写真アプリ）か「"ファイル"に保存」を選ぶ。ダウンロードも用意する。
- **まとめて保存**：編集した画像のうち、未保存のものだけが対象（保存済みも含めるか選べる）。共有メニューへ一度に渡す量を抑えるため、**最大10枚・50MBずつ**自動で分ける。1回分を保存し終えたら、次の分を準備する（共有はボタンを押した直後でないと動かないため、準備してからボタンを押してもらう）。
- 保存していない編集があるときにページを閉じようとしたら確認する。

- **フォルダに保存**（PCのChrome・Edgeのみ）：保存先を「開くフォルダの中の『編集済み』フォルダ」（初期値）・「別のフォルダ」・「使わない（ダウンロード）」から選べる。保存先の指定は IndexedDB に、選択は端末の設定に保存する。保存時に書き込みの許可を確認し（`requestPermission({ mode: 'readwrite' })`）、「編集済み」フォルダがなければ作る（`getDirectoryHandle(name, { create: true })`）。元のファイル名で保存し、同じ名前があれば上書きの確認を出す（まとめて保存では件数を示して1回だけ）。まとめて保存では、分けずにすべてを順に書き込み、同じ名前が重なる場合は「 (2)」などを付ける。

## 10. 確認すること（受け入れテスト）
1. メタデータ（位置情報のテキストなど）を入れたPNGを開き、四角でモザイクをかけて保存する → 範囲外のピクセルが元と完全に一致し、メタデータが残っていない。
2. 2本指で拡大してから、なぞって範囲を作れる。なぞっている間、始点へ結ぶ線が出ない。
3. なぞった範囲の線の近くをドラッグすると、その付近だけが伸びる。
4. JPEGは品質95%のJPEGで保存され、拡張子の大文字・小文字が元のまま（例：`photo.JPG`）。
5. 13枚を読み込み、1枚目の編集を他の12枚に適用し、1枚だけ元に戻してまとめて保存 → 12枚が10枚＋2枚に分かれて保存される。
6. 55枚を読み込もうとすると50枚で止まり、その旨が表示される。
7. 縦書きの吹き出しで、括弧と「ー」が縦向き、句読点が右上に表示される。
8. 叫びの吹き出しを登録し、ページを開き直しても残っている。別の吹き出しに呼び出すと、形と大きさが同じになり、文字は変わらない。
9. 縮小表示で小さな部品の中央をつかんでドラッグすると、拡大縮小ではなく移動になる。
10. iPhone SE の画面でも、画像の表示部分が十分に残り、横にはみ出さない。

# 第2部 AIエージェントがチャットの中で同じ編集を行う場合

Meta Muse などのAIエージェントに、アプリを使わずに同じ編集をさせる場合の仕様です。
エージェントが**プログラムを実行できる場合**（Pythonなど）に使えます。プログラムを実行できず、画像生成で描き直すだけのエージェントでは、元の画像が描き変わってしまうため、この仕様は守れません。

## 11. 守ること
1. 元の画像を描き直さない（画像生成AIで作り直さない）。元のピクセルに、プログラムで重ねて描く。
2. PNGはPNGのまま劣化なしで保存する。JPEGは品質95%で保存する。
3. メタデータ（EXIF・位置情報）を削除して保存する。
4. ファイル名は元の名前を基本にする。
5. 位置は「画像の幅・高さに対する割合（0〜1）」で考え、最後にピクセルに直す。

## 12. 編集指示の形式（JSON）
エージェントは、まずこの形式で「何をどこに入れるか」を決め、利用者に確認できるよう示してから実行する。

```json
{
  "edits": [
    { "type": "blur", "shape": "ellipse", "box": [0.42, 0.31, 0.12, 0.05], "strength": 12 },
    { "type": "mosaic", "shape": "rect", "box": [0.10, 0.80, 0.30, 0.06], "block": 16 },
    { "type": "fill", "shape": "rect", "box": [0.55, 0.20, 0.20, 0.04], "color": "#000000" },
    {
      "type": "bubble",
      "shape": "shout",
      "style": "burst",
      "box": [0.50, 0.15, 0.40, 0.18],
      "tail": [0.40, 0.38],
      "text": "ドカーン！",
      "vertical": false,
      "font": "gothic",
      "size": 0.05,
      "fill": "#ffffff",
      "line": "#000000"
    },
    { "type": "text", "pos": [0.5, 0.9], "text": "注目！", "size": 0.07, "color": "#ffffff", "outline": "#000000", "vertical": false },
    { "type": "arrow", "from": [0.2, 0.7], "to": [0.35, 0.55], "color": "#ff3b30", "width": 0.014 }
  ]
}
```

- `box` は `[中心x, 中心y, 幅, 高さ]`（すべて画像に対する割合）。
- `size`・`width` は画像の短辺に対する割合。
- 吹き出しの `shape`：`round`（角丸）・`ellipse`・`rect`・`shout`（叫び）・`thought`（思考）。`style`：叫びは `zigzag`・`burst`・`jolt`、思考は `cloud`・`puffs`。
- `tail` はしっぽの先端の位置（割合）。

## 13. 処理の手順（Python + Pillow の場合）
1. 画像を開き、EXIFの回転情報に従って正しい向きにする（`ImageOps.exif_transpose`）。
2. `blur`・`mosaic`・`fill` を順に処理する。範囲のマスク（楕円・四角、縁はなめらかに）を作り、`結果 = 元 + (効果 − 元) × マスク` で合成する。
   - ぼかし：`ImageFilter.GaussianBlur(strength)` を範囲より少し広く切り出してかける。
   - モザイク：画像全体の左上を基準に、`block` ピクセルごとの平均色で塗る。
3. 吹き出し・文字・矢印を、`ImageDraw` で上から描く。日本語フォント（Noto Sans JP など）を使う。縦書きは1文字ずつ上から下、列は右から左に置き、括弧と「ー」は90°回転させる。
4. 元の形式で保存する。PNGは `save(..., "PNG")`（メタデータを渡さない）、JPEGは `save(..., "JPEG", quality=95)`（`exif` を渡さない）。
5. 保存した画像と、使った編集指示（JSON）を利用者に返す。

## 14. 目や体の部位をぼかすとき
- 部位の位置はAIが画像を見て判断するため、ずれることがある。**必ず範囲を示して確認を取ってから**処理する。ずれていたら利用者が範囲を直すか、本アプリで自分で隠す。
- サービスの利用規約上、センシティブな画像を受け付けないことがある。その場合は本アプリで端末の中だけで処理する。
