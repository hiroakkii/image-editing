# モザイク編集（Webアプリ）

画像の一部を、指でなぞって囲った範囲や四角・楕円の範囲で指定し、**モザイク・ぼかし・塗りつぶし**をかけるWebアプリです。
iPhoneのSafariで動き、ホーム画面に追加すればアプリのように使えます。画像は端末の中だけで処理し、外部へは送信しません。

## できること

- **開く**：写真ライブラリ／ファイル（iPhoneの「開く」ボタンから選択）。パソコンではドラッグ＆ドロップでも開けます
- **範囲の指定**
  - なぞる：1本指でなぞった線の内側を選択します。なぞっている間は軌跡だけを表示し、指を離すと線が閉じます
    - 線の近くをドラッグ：その付近だけを伸ばしたり縮めたりできます（周りもなめらかに追従します。白い円が一緒に動く範囲で、拡大表示するほど細かく調整できます）
    - 四隅のハンドル：囲んだ形のまま全体を拡大・縮小します
    - 内側をドラッグ：移動します
    - 新しく囲み直すときは、今の範囲の外側からなぞり始めるか「解除」を押します
  - 四角・楕円：ドラッグで作成します。角のハンドルでサイズを変え、内側をドラッグすると移動します
  - 2本指でピンチすると拡大・縮小と移動ができ、拡大したまま範囲を指定できます。「全体」「等倍」ボタンもあります
- **編集**：モザイク（ブロックの大きさ 2〜200 px）、ぼかし（強さ 1〜100 px）、塗りつぶし（黒・白・グレー・任意の色）
  - 強さはスライダーでも数値入力でも変えられます。適用する前にプレビューで確認できます
- **元に戻す／やり直す**：何回でもできます
- **保存**：元画像とは別のファイルとして保存します
  - 「写真・ファイルに保存（共有メニュー）」→ iPhoneの共有シートから「画像を保存」（写真アプリ）か「"ファイル"に保存」を選びます
  - 「ダウンロード」→ ファイルアプリの「ダウンロード」フォルダに入ります

## 書き込む（吹き出し・文字など）

編集パネル上部の「**隠す**／**書き込む**」で画面を切り替えます。同じ画像を、両方の画面を行き来して編集できます。

- **追加できるもの**
  - 文字：フォント（ゴシック・明朝・丸ゴシック）、サイズ、色、太字、縁取り、揃え、**縦書き**
  - 吹き出し：角丸・楕円・四角・叫び（トゲトゲ）・思考（もくもく）。中の文字は自動で折り返し、収まらないときは吹き出しが広がります。塗り・線の色と線の太さも変えられます
  - 矢印（片側・両側）、枠（四角・角丸・楕円。強調用の赤丸など）、スタンプ（絵文字）
- **操作**
  - 部品をタップで選択し、ドラッグで移動します。四隅で拡大縮小、上の丸で回転（0°・90°などに吸い付きます）、吹き出しはオレンジの丸でしっぽを動かせます。矢印は両端の丸で向きと長さを変えます
  - 何もない所をドラッグすると画面が動き、2本指で拡大・縮小できます
  - 吹き出しの設定は「文字」と「吹き出しの形・色」のタブに分かれています
  - 複製・前面へ・削除ができます。「元に戻す／やり直す」は、隠す編集と書き込みの両方に使えます
- 書き込みは保存するまで何度でも直せます。保存するときに画像へ描き込みます（PNGは書き込んだ部分以外のピクセルは変わりません）
- 「他にも適用」で、書き込みも他の画像の同じ位置にコピーできます（隠す編集と書き込みのどちらをコピーするか選べます）
- 縦書きでは、括弧や長音記号（ー）は縦向きに回し、句読点と小さい「っ」「ゃ」などは右上に寄せています

## 複数枚の処理

- **まとめて開く**：「開く」で複数枚を選べます。続けて「開く」を押すと一覧に追加されます
- **一覧**：下のサムネイルか「‹ ›」で切り替えます。印の意味は、オレンジ＝未保存の編集あり、緑＝保存済みです。表示中の画像の「×」で一覧から外せます
  - 画像を切り替えても、それぞれの編集内容と「元に戻す」の履歴は残ります。適用前の選択範囲は次の画像に引き継がれます
- **他にも適用**：表示中の画像で適用した編集を、選んだ画像の同じ位置に追加します。同じサイズの画像は最初から選ばれています。サイズの違う画像は、縦横の比率で位置を合わせます。ずれた画像は、開いて「元に戻す」で取り消せます
- **保存**：上の「保存」は表示中の1枚だけを保存します。「まとめて保存」は編集した画像だけを、元のファイル名で保存します
  - 一度に共有メニューへ渡す量を抑えるため、**最大10枚・50MBずつ自動で分けて**保存します。1回分の保存が終わると次の分の準備が始まるので、ボタンを順に押してください
  - 保存済みの画像は対象から外れます（「保存済みの画像も含める」で含めることもできます）

### 一度に扱える量

- 読み込みの上限は **50枚・合計150MB** です。一覧の上にあるメーターで今の量を確認でき、上限を超えた分は読み込まず、その旨を表示します
- メモリを多く使うのは、ファイルの大きさよりも**画像の縦横のピクセル数**です。このアプリでは表示中の1枚だけを展開し、他の画像は元ファイルと編集手順だけを持っておくため、読み込む枚数が増えてもメモリはほとんど増えません
- 700KB〜1MB程度の画像（iPhoneのスクリーンショットなど）なら、50枚でも合計50MB前後で、上限に十分な余裕があります
- 上限の値は `app.js` の先頭にある `MAX_IMAGES`・`MAX_TOTAL_BYTES`（読み込み）と、`BATCH_FILES`・`BATCH_BYTES`（まとめて保存の1回分）で変更できます

## 保存形式とファイル名

| 元の形式 | 保存形式 | 画質 |
|---|---|---|
| PNG | PNG | 劣化なし（可逆）。編集していない部分のピクセルは元と完全に同じです |
| JPEG | JPEG | 品質 95% |
| HEIC | HEIC（ブラウザが対応している場合）／ 対応していなければ JPEG | 品質 95% |
| WebP | WebP（対応していなければ PNG） | 品質 95% |

- **ファイル名**：最初は元の名前（拡張子の大文字・小文字も含めて）がそのまま入っています。保存画面で自由に変えられ、「元の名前に戻す」で元の名前に戻せます。保存形式が変わるとき（HEIC→JPEGなど）だけ、拡張子が変わります
- **メタデータ**：撮影日時・位置情報（GPS）・カメラ情報・PNGのテキスト情報などは保存時にすべて削除されます。色を正しく表示するための色情報（Display P3 など）だけは残ります
- **画像の向き**：回転情報（EXIF）は削除されますが、画像そのものを正しい向きにしてから保存するため、見た目の向きは変わりません

## iPhoneで使う注意点

- 写真ライブラリから選ぶと、iOSがHEICを自動でJPEGに変換し、ファイル名も変わることがあります。**元のファイル名と形式を保ちたいときは、ファイルアプリから開いてください**（写真アプリの画像は、先に「"ファイル"に保存」しておくと確実です）
- 写真アプリに保存すると、写真アプリ側でファイル名が管理されます。ファイル名を確実に残したいときは、ファイルアプリに保存してください
- Safariで扱える画像は、およそ 1,677万ピクセル（4096×4096 相当）までです。iPhoneのスクリーンショットや 1200万画素の写真は問題ありませんが、4800万画素の写真は処理できない場合があります
- 半透明のピクセルを含むPNGは、ブラウザの仕組み上、編集していない部分の半透明ピクセルの値がごくわずかに変わることがあります（不透明な画像では起きません）

## 公開方法（iPhoneで使えるようにする）

HTTPSで公開する必要があります。いちばん簡単なのは GitHub Pages です。

1. GitHub でこのリポジトリの **Settings → Pages** を開きます
2. 「Build and deployment」の Source を **Deploy from a branch** にし、公開したいブランチと `/ (root)` を選んで保存します
3. 数分後に表示される URL（`https://<ユーザー名>.github.io/image-editing/`）を iPhone の Safari で開きます
4. 共有ボタン →「ホーム画面に追加」で、アプリとして使えます（一度開いたあとはオフラインでも動きます）

> 非公開（private）リポジトリで GitHub Pages を使うには、有料プランが必要です。無料で使う場合はリポジトリを公開にするか、Cloudflare Pages・Netlify などにフォルダごとアップロードしてください（ビルド作業は不要です）。

### パソコンで試す

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 操作（なぞる・図形・拡大）、読み込み、保存 |
| `effects.js` | モザイク・ぼかし・塗りつぶしと、範囲マスクによる合成 |
| `annotate.js` | 文字・吹き出し・矢印・枠・スタンプの描画（縦書きを含む） |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面への追加とオフライン動作 |
